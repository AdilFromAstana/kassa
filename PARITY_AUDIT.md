## 🔴 High-приоритет (что важнее всего)
- [x] ❌ **HallScreen** — Столы отображаются только в виде сетки одинаковых плиток. В iikoFront режим «Схема зала» — это SVG/canvas-план с произвольным расположением столов (drag-and-drop позиция, форма стола — прямоугольник/круг, размер). У нас фиксированный grid.
- [x] ❌ **MainMenuScreen / КАССА** — Кнопка «Открыть кассовую смену» при закрытой смене должна открывать Z-отчёт предыдущей смены (если был) и диалог с суммой начального остатка наличных. В нашей реализации `openCashShift` вызывается сразу без этого шага.
- [x] ❌ **ShiftCloseScreen** — В iikoFront шаг «Незакрытые заказы» содержит кнопку принудительного закрытия каждого заказа прямо из мастера. У нас есть только список без возможности закрыть/перенести.
- [x] ❌ **DocumentsScreen** — Нет разделения складов (источник / получатель) для Внутреннего перемещения. В iikoFront «Внутреннее перемещение» имеет два поля: склад-источник и склад-получатель. Здесь поле одно («Склад: Основной» жёстко).
- [x] ❌ **DocumentsScreen** — Акт приготовления и Акт переработки в iikoFront требуют указания блюда/полуфабриката результата (что будет приготовлено), а не только списываемых ингредиентов. Сейчас UI одинаков для всех типов документов — только строки ингредиентов без поля «Результат».
- [x] ❌ **DocumentsScreen** — Инвентаризация в iikoFront показывает учётный остаток рядом с фактическим (разница = отклонение). Здесь только одно поле «Факт. остаток», учётный остаток не отображается, расчёт отклонения не показывается.
- [x] ❌ **AttendanceScreen** — Нет фильтра по дате/периоду и выбора конкретного сотрудника из списка. В iikoFront «Редактировать явки» имеет фильтр-строку «Дата» с тач-календарём и выпадающий список сотрудников (не свободный ввод текста).
- [x] ❌ **BanquetsScreen** — Навигация по дате позволяет переключать только «Сегодня»/«Завтра» (2 элемента массива DAYS). В iikoFront стрелки позволяют листать любые даты без ограничений.
- [x] ❌ **BanquetsScreen** — Нет двойного клика/тапа на строку для открытия карточки банкета/резерва. Сейчас строки не кликабельны для редактирования — только кнопки «Пришёл»/«Снять».
- [x] ❌ **BanquetNewScreen** — Нет поля «Предоплата» (сумма и способ оплаты) в колонке БАНКЕТ/РЕЗЕРВ. В iikoFront карточка банкета содержит строки «Предоплата» и «Способ оплаты предоплаты».
- [x] ❌ **BanquetNewScreen** — Дата банкета жёстко задана как «10 июня 2026 г.» — нет пикера выбора даты. В iikoFront дата выбирается через тач-календарь при создании.
- [x] ❌ **EquipmentScreen** — В iikoFront настройка оборудования содержит вкладки: Чековый принтер, Денежный ящик, Дисплей покупателя, Считыватель карт, Весы, ФР — каждая с полями COM/IP/порт/скорость. У нас только список карточек «статус ОК/не подключено» без возможности изменить параметры подключения.
